# Paper Reader

An offline Android PDF reader that feels like reading a real paper book.

## Features

- Page-turn animation that folds the page like paper
- Paper page-turn sound on every flip
- Remembers the last page you read in each book
- Night reading mode with warm, dim light
- Reading streak (days in a row you read)
- Bookcase shelf view for your PDFs
- Large, clear text, works fully offline

## Get the app

Open the **Releases** page of this repository and download `app-release.apk` from the latest build. Open it on your Android phone to install (allow "install unknown apps" if asked).
